# WhatsApp AntiDelete Bot

> Read and save WhatsApp texts and photos with anti-delete functionality

## Features

✅ **Message Capture** - Automatically capture and save WhatsApp messages
✅ **Photo/Media Archiving** - Save photos and media files with metadata
✅ **Anti-Delete Detection** - Detect and preserve deleted messages
✅ **Timestamp Logging** - Track when messages were sent, received, and deleted
✅ **Secure Storage** - SQLite/PostgreSQL database for structured storage
✅ **API Interface** - RESTful API for programmatic access
✅ **Docker Ready** - Containerized deployment support
✅ **CI/CD Pipeline** - Automated testing, linting, security scanning

## Tech Stack

- **Language**: Python 3.9+
- **Framework**: FastAPI + Uvicorn
- **Database**: SQLite (dev) / PostgreSQL (prod)
- **WhatsApp Integration**: WhatsApp-Web.py
- **Testing**: Pytest
- **Deployment**: Docker & Docker Compose
